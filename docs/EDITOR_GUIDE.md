# Editor Guide

For Sherwood Forest Shores Board Members

## Logging in

1. Visit **sherwoodforestshores.org/admin**
2. Click "Login with GitHub"
3. Authenticate with your GitHub account (one of the authorized board emails)

## Common tasks

### Add a board meeting or event

1. Sidebar → **Events & Meetings**
2. Click **+ New Event**
3. Fill in date, time, location, category
4. If it includes Zoom, toggle "Includes Zoom?" on
5. Click **Publish** (top right) → **Publish now**
6. Site updates within ~30 seconds

### Update the board roster

1. Sidebar → **Board Members**
2. Click the member you want to edit
3. Update name, role, phone, email, photo
4. **Publish** → **Publish now**

### Add a new document

1. Upload the file to the HOA Google Drive folder
2. Copy the share link
3. CMS → **Documents & Forms** → **+ New Document**
4. Title, category, paste the Drive URL
5. **Publish**

### Post an announcement

1. **Announcements** → **+ New Announcement**
2. Title, date, summary (1-2 sentences for the homepage card)
3. Toggle "Featured on homepage?" to show on the front page
4. Write the full body
5. **Publish**

## Tips

- **Everything is automatically saved** as drafts. You can come back later.
- **Photos**: drag and drop into the photo field. They're auto-resized.
- **Markdown** is supported in long-form fields. Or just use the visual editor toolbar.
